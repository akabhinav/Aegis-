Quick Start Guide

  1. JWT Authentication: Login with username/password to get a token
  2. API Key: Use pre-configured API keys to access protected endpoints
  3. Basic Auth: Send credentials with each request (Base64 encoded)
  4. Test Endpoints: Try different endpoints to see role-based access control

cURL Examples

JWT:
curl -H "Authorization: Bearer YOUR_TOKEN" http://localhost:8080/api/me
API Key (Header):
curl -H "X-API-Key: demo-key-alice-12345" http://localhost:8080/api/me
API Key (Query):
curl "http://localhost:8080/api/me?api_key=demo-key-alice-12345"
Basic Auth:
curl -u demo:password http://localhost:8080/api/me

Features
